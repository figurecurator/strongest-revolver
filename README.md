# 최강의 리볼버 / The Strongest Revolver

RainbowSoft의 서부 결투 게임 프로토타입입니다. 타이밍을 읽고 정확하게 조준하며, 교리와 장비를 선택해 나만의 총잡이를 키워갑니다.

[공개 프로토타입 플레이](https://maxtortime.itch.io/strongest-revolver) · [RainbowSoft](https://rainbowsoft.co.kr)

## 실행

`index.html`을 브라우저로 열면 플레이할 수 있습니다. 별도 빌드나 패키지 설치가 필요하지 않습니다. 게임 코드(HTML·CSS·JavaScript)는 한 파일에 들어 있으며 배경 이미지는 `assets/background-concepts/`에 있습니다. 글꼴은 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴로 표시됩니다.

- Space: 격발 / 길게 누르면 연사
- Shift: 집중
- R: 재장전
- 한국어 / English 전환 및 브라우저 로컬 저장 지원

## 공개 버전

v0.18 로컬 프로토타입을 기반으로 한 공개 소스 스냅샷입니다. itch.io의 배포 버전과 다를 수 있습니다. 운영용 플레이 데이터 수집 주소는 제거했고, 이 버전은 익명 데이터 공유 기능과 외부 전송이 비활성화돼 있습니다. 비공개 저장소의 개발 기록, 운영 설정, 데이터베이스, 과거 버전은 포함하지 않습니다.

## 검증

Node.js가 있으면 `node scripts/test_expedition_prototype.js`로 기존 원정·보상·저장 동작 검증을 실행할 수 있습니다.
